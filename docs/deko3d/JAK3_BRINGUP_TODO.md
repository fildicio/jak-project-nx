The proven recipe is the jak2 dkgl hybrid (§7.2 in `DKGL_HYBRID_BRIEF.md`): the unchanged GL
renderers run through dkgl capture→replay, the native world passes (tfrag/tie/shrub/…) draw
from the DMA chains, and one sorted bucket table drives the frame order.

**The good news (verified 2026-11-18): jak3 needs no new rendering machinery.** GL already
registers every jak3 renderer in `OpenGLRenderer::init_bucket_renderers_jak3()`
(`game/graphics/opengl_renderer/OpenGLRenderer.cpp:511-786`), `jak3::BucketId` is complete
(`game/graphics/opengl_renderer/buckets.h:415-657`, `MAX_BUCKETS = 587`), and the y-scale
constants are shared with jak2 (non-Jak1 → `use_jak2_verts()`, `Shader.cpp`). The work is
census → table → wiring → hardware, exactly like jak2 phase 1/2.
